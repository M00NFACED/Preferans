# Преферанс — игра с друзьями

Своя версия преферанса в варианте «Пуля» (как в [Преферанс Мультиплеер](https://yandex.ru/games/app/preferans-multipleer-225506) на Яндекс Играх), но:

* **без рекламы** — вообще никакой;
* **без «багов запуска»** — сервер на Python, клиент без сборки, есть автопереподключение;
* **свой сервер** — комнаты по коду, можно звать друзей через интернет;
* **боты** — можно играть вдвоём (третий игрок — бот) или втроём с друзьями;
* **исходники открыты** — можно доработать под себя.

Технологии: backend — FastAPI + WebSocket, фронтенд — обычные HTML/CSS/JS без сборщика
(то есть `node` и `npm` не нужны вообще).

### Что есть в игре

* **Настоящие карты**: фигуры мастей нарисованы SVG, у числовых карт — классическая
  раскладка пипсов (7/8/9/10), туз — крупный значок масти, у дам, валетов и королей —
  свои рисунки с тиарой, шляпой и короной, так что карты различаются с одного взгляда.
  Цвета мастей приглушённые, без чёрно-красного контраста: пики #3C4368, трефы #235955,
  бубны #F06B3F, черви #F03464. Козыри подсвечены золотой рамкой.
* **Подписи карт**: каждый игрок сам выбирает — кириллицей (В Д К Т) или латиницей
  (J Q K A). Переключается в меню, сохраняется.
* **Стол**: сукно с текстурой, деревянный борт, эмблема из мастей, подсветка текущего
  игрока, последняя взятка остаётся на столе, пока её не разыграют.
* **Табло**: у каждого видно пулю (полоска прогресса), гору и висты; текущий игрок подсвечен.
* **Звук**: карты, заявки, конец раунда — синтезируются на лету (WebAudio), выключаются
  кнопкой ♪ в шапке, выбор запоминается.
* **Анимации**: раздача карт, выкладывание взятки, последняя взятка гаснет через пару секунд,
  конфетти на финале матча.
* **Журнал партии** — сворачивается, на телефоне закрыт по умолчанию.
* **Работает на телефоне**: проверено на 390×844, карты в руке укладываются в экран.
* **Крупный экран**: на мониторе от 1500 px интерфейс масштабируется — карты, шрифты
  и кнопки становятся заметно больше.
* **Бейджи игроков**: «заказчик» (и его контракт), «вист», «без виста», «мизер» — сразу видно,
  кто что объявил.
* **Шпаргалка** — кнопка «?» в правом нижнем углу (и в меню) — три вкладки:
  * «По моей руке»: отмечаете карты — показывает, сколько взяток они набирают, и в какой
    масти у мизериста дыра;
  * «Таблица комбинаций»: сколько взяток набирает каждая комбинация (из классических
    «Правил преферанса»);
  * «Ловля мизера»: дыры в мастях и вероятность поймать мизера.
* **Защита от рассинхрона**: если клиент обновился, а сервер — нет, игра предупредит
  «перезапустите сервер» (частая причина «ничего не нажимается»).

### Слепая игра («в тёмную») — включена по умолчанию

В комнате карты раздаются **закрытыми**: сначала никто свою руку не видит. На торге каждый
решает сам:

* **заявить контракт вслепую** — не видя карт; такую заявку можно перебить только
  контрактом **следующего уровня** (6 пик вслепую — только заявкой на 7), как в
  классическом преферансе;
* **взять мизер вслепую** — и не взять ни одной взятки;
* **открыть карты** — и дальше торговаться как обычно, уже видя руку.

Кто заявил контракт вслепую и выиграл торг — после торгов открывает свои карты, получает
прикуп и дальше играет как обычно. Премия в пулю и штраф в гору за такой контракт
**удваиваются**. Если слепую заявку перебили контрактом на 9, мизер отменяется, а 9
становится обычным контрактом.

В лобби это можно выключить («Слепая игра» → «Выключена»), тогда карты раздаются
открытыми и торг идёт как обычно.

Дополнительно: если вистовал только один игрок, он выбирает — «в тёмную» (карты не видны,
ставки удваиваются) или «в светлую» (карты видны, ставки обычные).

## Быстрый старт (на своём компьютере)

Windows:

```
run.bat
```

macOS / Linux:

```bash
./run.sh
```

Или вручную:

```bash
python -m venv .venv
.venv\Scripts\activate        # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Открыть <http://127.0.0.1:8000>.

Нужен Python 3.10 или новее. Больше ничего ставить не надо.

## Как сыграть с друзьями через интернет

### Вариант 1 — туннель с компьютера (бесплатно, без регистрации)

Игра крутится на вашем компьютере, а друзья заходят по публичной ссылке.

1. Запустите сервер: `run.bat`
2. В **другом** окне запустите `tunnel.bat` — он поднимет сразу несколько туннелей
   (localhost.run, pinggy, cloudflared) и напечатает все полученные адреса.
3. Скрипт каждые 15 секунд проверяет каждый адрес и пишет его состояние:
   `ok` / `заглушка (кнопка Enter site)` / `HTTP 530` / `не отвечает`.
   Проверьте адреса с телефона **без VPN** и отправьте друзьям тот, что открывается.

Пример вывода:

```
[localhost.run] https://89deadf7a3b49a.lhr.life
[cloudflared]   https://roster-here-gel-rome.trycloudflare.com
[pinggy]        https://krann-95-25-211-90.run.pinggy-free.link

[localhost.run] https://89deadf7a3b49a.lhr.life — ok
[pinggy]        https://krann-95-25-211-90.run.pinggy-free.link — заглушка (кнопка Enter site)
[cloudflared]   https://roster-here-gel-rome.trycloudflare.com — HTTP 530
                 подсказка: адреса Cloudflare в РФ недоступны без VPN
```

> В РФ часть адресов фильтруется: `.lhr.life` может не открываться с телефона,
> а `trycloudflare.com` (Cloudflare) — вовсе недоступен без VPN. Поэтому и сделано
> несколько провайдеров сразу: вы просто выбираете рабочий.
> Если не подошёл ни один — вариант 2 (хостинг), там адрес постоянный и фильтрации нет.

Мелочи, о которых стоит знать:
* **pinggy** иногда не подключается («сервис не отвечает») — он режет анонимные
  туннели при частых переподключениях с одного IP. Скрипт это покажет, попробуйте позже.
* **localhost.run** может объявить адрес дважды или сменить имя хоста при переподключении —
  скрипт проверяет каждый адрес отдельно, отдайте друзьям тот, что в статусе `ok`.

Альтернативные команды, если захотите запустить туннель вручную:

| Способ | Команда | Нюанс |
|---|---|---|
| localhost.run | `ssh -R 80:localhost:8000 nokey@localhost.run` | адрес `https://xxx.lhr.life` |
| pinggy | `ssh -p 443 -R0:localhost:8000 a.pinggy.io` | при первом заходе друзья жмут «Enter site» |
| cloudflared | `tools\cloudflared.exe tunnel --url http://localhost:8000 --protocol http2` | адрес в Cloudflare — в РФ нужен VPN |

> Сервер должен быть запущен всё время, пока играете. Адрес туннеля меняется при каждом
> перезапуске.

**Про блокировки и VPN.** Игра полностью автономна: CSS, JS, шрифты и карты отдаёт ваш
собственный сервер — ни одного обращения к CDN, Google Fonts, аналитике или SDK. Поэтому
работает везде, где доступен ваш туннель, и не ломается в сетях, где Cloudflare заблокирован.

### Вариант 2 — бесплатный хостинг (постоянный адрес, без фильтрации)

В проекте есть готовые конфиги:

| Платформа | Файл | Как |
|---|---|---|
| **Render** (free) | `render.yaml` | New → Blueprint → указать репозиторий. Бесплатно, но сервер «засыпает» после 15 минут простоя (клиент пингующий сервер, так что во время игры не засыпает) |
| **Railway** | `railway.json`, `Dockerfile` | New Project → Deploy from repo. Дают стартовый кредит |
| **Fly.io** | `Dockerfile` | `fly launch` — потребуется карта |
| **Свой VPS** | `Dockerfile` | `docker build -t pref . && docker run -p 8000:8000 pref` |

> Из этих площадок в РФ доступны все (у Render/Railway/Fly нет CDN-зависимостей для
> самого приложения). Если хочется «без VPS и без туннелей» — берите Render или Railway.

**Как задеплоить на Render (пошагово)**

1. Выложите проект на GitHub. Без `gh` это делается так:

   ```
   cd D:\projects\CardGame
   git init
   git add .
   git commit -m "Преферанс: сервер и клиент"
   git branch -M main
   git remote add origin https://github.com/<ваш-ник>/<репозиторий>.git
   git push -u origin main
   ```

   (`.gitignore` уже настроен — виртуальное окружение и `tools/cloudflared.exe` в репозиторий не попадут.)

2. На <https://render.com> → **New → Blueprint** → указать свой репозиторий.
   Render сам прочитает `render.yaml` и задеплоит.
3. Через пару минут выдаст адрес вида `https://<имя>.onrender.com` — его и шлёте друзьям.

То же самое с Railway: **New Project → Deploy from repo** (подхватит `railway.json` и `Dockerfile`).

> Free-тариф Render усыпляет сервер после 15 минут простоя. Клиент пингует сервер каждые
> 25 секунд, поэтому во время партии сервер не засыпает; между играми может — состояние
> комнат при этом сбрасывается (это нормально, партия всё равно начинается заново).

После деплоя откройте адрес, придумайте комнату, отправьте друзьям **код комнаты** (5 символов) —
они вводят его на главной странице.

> Важно: состояние комнат живёт в памяти, поэтому сервер должен работать **одним процессом**
> (`--workers 1`, как уже настроено в `railway.json`, `render.yaml`, `Procfile` и `Dockerfile`).
> Перезапуск сервера стирает текущие комнаты — на результатах матча это не страшно.

### Вариант 3 — в одной сети (Wi-Fi)

Запустите сервер с `--host 0.0.0.0` (так уже настроено в `run.bat`) и дайте друзьям
свой локальный IP: `http://192.168.x.x:8000`.

## Правила (вариант «Пуля»)

Полный текст правил есть в самой игре (кнопка «Правила» на главной странице).
Кратко:

* **Колода**: 32 карты, 7–А в четырёх мастях. Трое игроков, по 10 карт, прикуп — 2 карты.
  Всего 10 взяток.
* **Торг**: игроки по очереди (от сдатчика) называют контракт или пасуют. Заявка должна быть
  строго выше предыдущей; «пас» означает выбывание из торговли, и заявка паснувшего обнуляется. Лестница — 25 контрактов:
  `6 пик → 6 треф → 6 бубн → 6 червей → 6 без козыря → 7 пик → … → 10 без козыря`.
  Козырь — это масть контракта. Торг идёт, пока два игрока подряд не спасуют;
  если пасуют все трое — играются **распасы** (без козыря, каждый играет за себя
  и старается взять как можно меньше взяток).
* **Мизер**: можно взять отдельно — не взять ни одной взятки. По классическим правилам
  мизер объявляется **только первой заявкой** игрока (не после паса) и может быть
  **перебит заявкой на 9**: если её перебили, мизер отменяется, а заявка на 9 становится
  обычным контрактом.
* **Прикуп**: после торга прикуп раскрывают — его видят все. Заказчик сбрасывает две
  ненужные карты из своих десяти, и только потом к нему в руку уходят две карты прикупа
  (снова десять карт). После этого прикуп никому не показывается. Потом заказчик
  назначает контракт — не ниже своей заявки. Можно дополнительно взять
  **«без 3 взяток»** (пообещать взять меньше трёх взяток).
* **Вист**: после назначения контракта соперники отвечают «вист» или «пас».
  Вистующий обязан взять своё число взяток, иначе штраф. Для контрактов 6 и 7 доступен
  **полвиста** (вдвое меньше). Если вистуют оба соперника, каждый отвечает и
  рассчитывается отдельно. Недобор виста пишется в гору вистующему, а заказчику
  за недобор идут очки в пулю.

  | Контракт | Взяток висту | Висты |
  |---|---|---|
  | 6 | 4 | 8 |
  | 7 | 2 | 8 |
  | 8 | 1 | 6 |
  | 9 | 1 | 8 |
  | 10 | 1 | 10 |

* **Взятки**: ходить нужно в масть, если она есть; иначе — козырем; если нет и козыря —
  любой картой. Взятку берёт старшая карта масти (или старший козырь), победитель ходит дальше.
* **Очки**: у каждого **пуля** (своя дорожка), **гора** (долг) и **висты** (счёт матча).
  * Сыгранный контракт N взяток → `(N−5)×2` очка в свою пулю. Очко в пуле = 10 вистов.
  * Недобранная взятка → `(N−5)×2` очка в гору (в варианте «Ленинград» ×2),
    соперникам идут очки в их пули.
  * Мизер: сыгран → 10 очков в пулю, каждая взятая взятка → 10 в гору.
  * Распасы: каждая взятка → очко в гору (штраф растёт: 1, 2, 3), кто не взял ни одной —
    пишет очко в свою пулю. Любой сыгранный контракт сбрасывает серию распасов
    (амнистия): следующая серия снова начинается с 1.
  * **Конец матча**: «Сочи» — когда у всех заполнена пуля; «Ленинград» — когда сумма очков
    в пулях ≥ длина пули × 3. Побеждает тот, у кого больше вистов.
  * Висты могут быть отрицательными — это долг игрока, а не ошибка счёта.
  * Длина пули настраивается: 5 / 10 / 15 / 30 / 50.

## Как устроен проект

```
app/
  cards.py     колода, старшинство, определение победителя взятки
  rules.py     лестница контрактов, таблицы очков, варианты игры
  game.py      движок партии: фазы, ходы, расчёт раунда
  bot.py       бот: торг, снос, вист, ход картой
  rooms.py     комнаты, посадка игроков, боты, рассылка состояния
  main.py      FastAPI + WebSocket, обработка сообщений, статика
web/
  index.html   экраны: главная, лобби, стол, итоги, правила
  css/style.css  оформление: сукно, карты, табло, адаптив под телефон
  js/cards.js    рисование карт (SVG-масти, угловые индексы, рубашка)
  js/sound.js    звук на WebAudio, без внешних файлов
  js/app.js      клиент: WebSocket, отрисовка, действия, анимации
tools/
  simulate.py  прогон матчей ботов без сети
  stats.py     статистика: типы раундов, точность бота
  botcheck.py  проверка оценки руки против реальных взяток
  e2e.py       сквозной тест: полный раунд + переподключение
  e2e_multi.py сквозной тест на двоих живых игроков
  e2e_blind.py сквозной тест слепой игры (слепая заявка, удвоение ставок)
  tunnels.py   несколько публичных туннелей сразу + проверка ссылок
  trace.py     покадровый разбор партии
  shot.py      скриншоты интерфейса через headless Chrome (--mobile — телефон)
  serve.ps1    запуск/перезапуск локального сервера
```

Протокол — JSON по WebSocket (`/ws`). Клиент шлёт `create/join/resume/bid/drop/declare/whist/
catch_mizer/play/next_round`, сервер шлёт `state` (персональное состояние с вашей рукой),
`notice`, `error`, `pong`.

### Тесты

```bash
python tools/e2e.py        # сквозной тест: раунд с ботами + переподключение
python tools/e2e_multi.py ws://127.0.0.1:8000/ws   # двое живых игроков + бот (нужен запущенный сервер)
python tools/simulate.py 5 # прогон матчей ботов
python tools/stats.py 20 30   # статистика игр
```

## Что можно доработать

* Таймер на ход (в оригинальной игре есть `EndMove`).
* Договор «беру N взяток» прямо во время игры и «ловить мизер» (ловить мизер уже реализовано).
* Свои карты (скины), звуки, анимации.
* Постоянное хранилище результатов (сейчас состояние только в памяти).
